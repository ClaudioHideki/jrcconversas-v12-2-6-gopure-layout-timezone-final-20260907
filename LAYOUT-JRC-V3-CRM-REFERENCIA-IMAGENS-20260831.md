# JRC Layout V3 — CRM baseado nas imagens de referência

Ajustes visuais feitos sobre o pacote `JRC-CAMPANHAS-LAYOUT-V2-20260831` sem remover os módulos existentes.

## Ajustes principais
- CRM volta a permanecer visível na barra lateral como módulo "Novo" mesmo quando a feature ainda não está ativa; a ativação continua sendo controlada pela conta/permissão.
- Cabeçalho do CRM Comercial modernizado com navegação horizontal colorida para Visão Geral, Indicadores, Leads, Negócios, Funil, Minha Carteira, Atividades, Agenda, Produtos e Propostas.
- Tema visual do CRM aproximado das imagens de referência: fundo claro, cards arredondados, sombras suaves, botões coloridos e navegação mais compacta.
- Agenda comercial refeita em formato semanal, com calendário lateral, grade de sete dias e painel da próxima atividade.
- Atividades ganhou filtros/chips superiores e card de taxa de conclusão.
- Mantidos os componentes e APIs existentes para preservar a funcionalidade já implementada.

## Observação
O layout é uma implementação funcional inspirada nas imagens de referência. Como as imagens são mockups estáticos, alguns dados/ações dependem dos endpoints e registros reais do CRM.
